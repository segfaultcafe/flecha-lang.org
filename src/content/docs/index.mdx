			<div class="eyebrow">The language</div>
			<h2>Systems code with fewer hidden moves.</h2>
			<p>Flecha makes low-level work visible: explicit allocation, checked references and slices, ownership contracts, and native output without a garbage-collected runtime.</p>
			<p>Its compiler pairs those controls with readable diagnostics and a growing static-analysis pipeline.</p>
		</div>
		<div class="code-panel">
			<div class="code-panel__bar"><i></i><i></i><i></i>factorial.fl</div>
			<pre><code>{`i32 factorial(i32 n) {
    if n <= 1 {
        return 1;
    }
    return n * factorial(n - 1);
}

void main() {
    result := factorial(5);
    stdoutln(result);
}`}</code></pre>
