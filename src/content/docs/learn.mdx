Flecha is easiest to learn as a sequence of working programs, not as a tour of
the reference manual. These five tracks form the official v0.3 learning path.
Each one names its prerequisites, ends in a useful project, and links to the
reference only when you need the complete contract.

Start by [installing Flecha v0.3.0](/install/). The tutorials use matching
`flecha` and `longbow` binaries and commands exercised by the documentation CI.

<CurriculumCards />

## How progression works

Complete the tracks in order. Previous and Next links belong only to this
curriculum, including the intentional hand-off from one level to the next.
Reference pages, examples, release notes, and specifications remain standalone:
they provide related reading, not an accidental learning sequence.

The Unsafe track is last deliberately. `unsafe` is an explicit boundary for
operations safe Flecha cannot express; it is never a shortcut to presumed
performance. Prefer a safe equivalent whenever one exists.
