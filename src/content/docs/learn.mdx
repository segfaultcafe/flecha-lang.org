This section contains two independent tutorial sequences. The main sequence
covers the language and toolchain in five levels. ARROWFALL applies a subset of
the same features while building one terminal game in seven cumulative steps.

Start by [installing Flecha v0.3.0](/install/). The tutorials use matching
`flecha` and `longbow` binaries and commands exercised by the documentation CI.

<CurriculumCards />

## ARROWFALL tutorial

ARROWFALL is separate from the five-level sequence. It starts with a static
terminal scene and adds state, input, collision, turns, archery, deterministic
randomness, tests, and a release build.

## Navigation

Previous and Next links in the main sequence connect its five levels.
Reference pages, examples, release notes, and specifications remain standalone:
they are not part of tutorial pagination.

The Unsafe level is last. It documents operations that safe Flecha cannot
express and retains a safe alternative wherever one exists.

ARROWFALL has its own seven-step Previous/Next sequence. Its source, commands,
input, output, and terminal frames come from fixtures validated with official
Flecha and Longbow v0.3.0.
