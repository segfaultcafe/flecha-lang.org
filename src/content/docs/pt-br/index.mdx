export const testExample = `module algorithms_test;

@imports
    :: root::containers::algorithms
    :: lib::std::tests::testing
    :: lib::std::tests::asserts;

test index_of_finds_the_first_match(&testing::UnitTest t) {
    [5]i32 values = [10, 20, 30, 20, 40];

    index, found := algorithms::index_of<i32>(values[:], 20);
    asserts::is_true(t, found, "index_of finds a present value");

    usize expected = 1;
    asserts::equal<usize>(
        t, &expected, &index, "index_of returns the first match"
    );
}`;

		<div class="eyebrow">A promessa de projeto</div>
		<h2>Linguagem simples. Sistemas seguros. Performance nativa.</h2>
		<p>A Flecha busca permanecer muito mais simples que C++ e Rust sem abrir mão de segurança de memória ou controle de baixo nível. Um conjunto pequeno de mecanismos — ownership explícito, referências e slices verificados, destruição determinística, erros como valores e fronteiras <code>unsafe</code> estreitas — deve se combinar em bibliotecas poderosas, sem exigir um novo recurso da linguagem para cada domínio.</p>

		<h2>Uma linguagem capaz de sustentar a própria implementação.</h2>
		<p>A Flecha caminha para um compilador autocontido escrito em Flecha, com performance nativa na mesma classe de uma implementação equivalente em C++. Formatos de dados, redes, I/O assíncrono, metaprogramação, criptografia e integrações nativas exigentes ajudarão a provar a linguagem pelo caminho.</p>
		<p>Esta é uma direção, não uma lista imutável. O destino está claro, enquanto a linguagem continua livre para descobrir formas melhores de chegar até ele.</p>
